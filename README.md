# rebirth-plugin

rebirth-plugin 是一个基于 Yunzaibot 的聊天娱乐插件，主要用于为用户提供异世界转生的娱乐功能。用户可以通过该插件生成和查看自己的转生信息。

## 指令

| 指令 | 说明 |
|---|---|
| `异世界转生` | 生成/查看当日转生信息（经典卡，无 AI 立绘） |
| `#ai异世界转生`（`#` 可省略、大小写不敏感） | 转生 + 调用即梦 AI 生成角色立绘，渲染成整卡 |
| `#异世界加点 力量 2` | 分配 RPG 属性点（力量/敏捷/智力/魅力） |
| `#异世界等级` / `#异世界面板` / `#异世界属性` | 查看等级、经验、属性点 |

## 数据配置

### 种族 / 职业属性：一个文件一个条目

种族与职业的属性加成放在两个独立目录里，**一个种族/职业一个 JSON 文件**：

```
config/races/精灵.json        # 种族：文件名即种族名
config/jobs/战士.json         # 职业：文件名即职业名
```

文件内容（示例）：

```json
{
  "name": "精灵",
  "strength": -1,
  "agility": 3,
  "intelligence": 2,
  "charisma": 1
}
```

- `name` 可省略，省略时以文件名为准；四维键缺省为 0，可用负数。
- 也支持中文键 `力量` / `敏捷` / `智力` / `魅力`。
- **增删文件即增删种族/职业**：插件启动时扫描目录，新增/移除会写进启动日志。
- 实际属性 = `1~10 随机 + 种族加成 + 职业加成`。

### 收集图鉴

用户每次转生获得的种族/职业会被**累计**记录（永久，不随每日转生重置），转生时回复会附上进度：

```
【异世界收集】种族 12/100 · 职业 8/100
本次新收集：种族「精灵」、职业「游侠」
```

重复抽到同一种族/职业只累加获得次数，不再计入「新收集」。

### 其它配置

- `config/rebirth.default.json`：外观与技能词条（性别/体型/发色/瞳色/特殊技能）。
  其中的 `races`/`jobs` 仅用于首次初始化导出单文件，以及目录为空时的兜底。
- `config/rpg.default.json`：等级曲线、签到经验、属性点规则。
- `config/ai.default.json`：即梦生图（需填 `jimeng.sessionid`）。
- 运行时 `config/*.json` 不入库，缺失时由 `app/core/infra.js` 从 `*.default.json` 自动生成。

## 代码结构

按「运行逻辑」分层，共 **6 个模块**（`app/` 下）：

```
app/
├─ index.js        入口：启动自检（配置 + 种族职业扫描）+ 导出 3 个命令类
├─ commands.js     接口层：`异世界转生` / `#?ai异世界转生` / `#异世界加点·等级`
└─ core/
    ├─ infra.js    基础层：日志 · 配置 · 路径/日期/随机/文件/用户信息 · SQLite 连接
    ├─ data.js     数据层：内容目录 · 转生信息 · RPG 等级 · 收集图鉴（全部持久化读写）
    ├─ image.js    产出层：转生卡 HTML→图片渲染 · 即梦 AI 文生图
    └─ flow.js     编排层：签到/加成钩子 · 收集登记 · AI 立绘流水线 · 卡片数据组装
```

依赖严格单向：`commands → flow → data/image → infra`，无环。改 `config/*.json`、`core/infra.js`、`core/data.js`、`core/image.js` 需重启 bot。

### 产物位置

- 转生卡片图：`tmp/rebirth/{日期}-{QQ}.png`
- AI 立绘原图：`tmp/rebirth/ai/{QQ}_{yyyyMMdd}.png`
- 均在 `tmp/`（已被 gitignore）内，可随时清理；清理后下次转生会自动重新生成。
