# 职业属性配置

一个职业 = 一个 JSON 文件，文件名即职业名（也可以在里面写 `name` 字段覆盖显示名）。

## 字段

| 键 | 含义 | 说明 |
|---|---|---|
| `name` | 职业名 | 可选；不写则用文件名（去掉 .json） |
| `strength` | 力量加成 | 可为负数，缺省 0 |
| `agility` | 敏捷加成 | 同上 |
| `intelligence` | 智力加成 | 同上 |
| `charisma` | 魅力加成 | 同上 |

也可以用中文键 `力量` / `敏捷` / `智力` / `魅力` 代替英文键。

## 示例（`战士.json`）

```json
{
  "name": "战士",
  "strength": 2,
  "agility": 1,
  "intelligence": 0,
  "charisma": 0
}
```

## 规则

- **增删文件即增删职业**：往本目录丢一个新 `.json` 就多一个可抽到的职业，删掉即移除。
- 插件**启动时扫描**本目录；新增/移除会在启动日志里列出。改完文件需重启 bot 生效。
- 属性加成 = 该职业文件的四维值；实际属性 = `1~10 随机 + 种族加成 + 职业加成`。
- 文件名以 `_` 开头、或不是 `.json` 的文件会被忽略（可放说明文件）。
- 支持 UTF-8 BOM、整行 `//` 注释与尾随逗号，方便手改。
